# Chess

The project has one chess game: [ChessArena.html](./ChessArena.html). It is a local two-player game with legal moves, check/checkmate and draw detection, castling, en passant, promotion, move history, undo, and board flipping.

Enter player names in the setup panel and play by clicking a piece and destination square or by dragging a piece. The chess rules library is loaded from a CDN, so an internet connection is required.
